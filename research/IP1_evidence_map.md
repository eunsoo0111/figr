# 투자포인트 1 근거 지도

> 이 파일은 투자포인트 1의 논리 고리마다 **찬성 근거 / 반대 근거 / 상태 / 다음에 볼 것**을 모아 둡니다. 새 자료를 읽을 때마다 해당 고리에 한 줄씩 추가하세요.
> 상태 표기: 🟢 근거 충분 · 🟡 근거 있으나 숫자 부족 · 🔴 미검증·반증 있음

## 논리 구조 (현재 버전)

```
[0] HELOC(주택 지분 접근) 시장의 구조적 성장
      │
      ▼
[1] 파트너(판매 쪽) 증가 ── 특히 [1-B] 은행의 신규 진입
      │   왜? ↓
[2] 해자: LOS(진입로) → Connect(유동성) 고착
      │
      ▼
[3] 매수자(구매 쪽) 유입 ── 은행·IMB가 매수자로도 들어옴
      │
      ▼
[4] Connect 양면 네트워크 효과 → 거래량↑, 가격↑, 파트너 수익↑ → [1]로 순환
      │
      ▼
[5] FIGR 실적: 거래량 × 수취율(↓) → 공헌이익·EBITDA 마진(↑)
```

**제안하는 문장 수정 (자료 5종 반영)**
- [2]의 인과를 "LOS를 쓰면 Connect로 올 수밖에"에서 **"Connect 유동성 때문에 LOS를 쓰고, LOS를 쓰면 Connect로 이어지는 길이 자동으로 깔린다"**로.
- [1-B]의 은행을 **판매자이자 매수자**로. 은행 진입은 양면을 동시에 키우는 유일한 참여자라는 게 핵심 주장.
- [0]을 "HELOC 점유율"이 아니라 **"락인 효과가 만든 지분 접근 수요 + Figure가 여는 그린필드(Figure factor 2.6배) + 금리 하락 시 1순위 확장"**으로.
