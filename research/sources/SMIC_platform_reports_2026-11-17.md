## 1. Doximity — 「한쪽을 다 잡았으니 반대쪽은 올 수밖에」

**투자포인트 구조**
- Point 1 「모든 의사들의 선택」 = **이용자 쪽**: 미국 의사 면허 소유자 80% 이상 가입, 의대생 90% 이상 가입. 활성 이용자 비율 30% vs 링크드인 48.5% → 성장 여력. 왜 쓸 수밖에 없나: HIPAA 때문에 공개 SNS를 못 씀, 최신 의학 정보, 채용까지 한 바구니(「카카오톡처럼 의대에 입학하면 가입이 당연」), DocsGPT가 사전승인(PA) 고통을 해결(AMA 설문: 의사 93% 치료 지연 경험, 주 13시간 PA 업무)
- Point 2 「해자 구축 완료, 이제 돈을 벌 차례」 = **고객(제약사) 쪽**, P×Q로 분해
  - Q: 광고 예산 72.2%가 이미 디지털, 제약사의 표적청중이 곧 의사 → 의사 80%가 있는 곳이 가장 효율적
  - **ROI로 증명**: 의사 대상 광고 ROI 영업사원 1.7배, 일반 디지털 2.46~4.2배, Doximity 11배
  - **고객 코호트**: 연 $10만 이상 지불 고객 251 → 346곳, $50만 이상 71 → 114곳, 순매출 유지율(NRR) 항상 110% 이상, 상위 20곳 122%
  - P: 새 광고 지면(진료 중 POC, 처방 중 Formulary), 클라이언트 포털 업셀, 무료 → 유료 전환(「독점 기업의 레퍼토리」)

**FIGR에 가져올 것**
| Doximity 도구 | FIGR 대응 |
|---|---|
| 침투율 한 줄(의사 80%, 의대생 90%) | **상위 20개 IMB 중 10곳**, 식별 파트너의 2025 1순위 실행 $339B = 미국 1순위의 **15.2%**(Ottavi), 회사 발표 파트너 대출 $500B+ |
| 벤치마크로 여력 보여 주기(AU 30% vs 링크드인 48.5%) | 파트너 판매망 × HELOC 부착률 = 잠재 물량 vs 현재 물량 (아래 가이드 계산 예시) |
| 한쪽의 고통(PA)을 설문 숫자로 | IMB의 HELOC 고통: 건당 $5~7천 비용, 기술 스택·장부 없음, 업계 실행 전환율 49%(MBA 2024) |
| 반대편이 오는 이유를 **ROI로** | 매수자: 대출 쿠폰 약 8.75% vs 요구수익률 7.5~8%, HELOC AAA 6.2~6.5%가 같은 등급 회사채보다 높음, AAA 255 → 135bp |
| **NRR(기존 고객이 더 쓴다)** | 판매 쪽: 기존 파트너가 1년 뒤 **40% 이상 더** 실행, 올해 성장의 40% 이상이 기존 파트너(O2). 매수 쪽: 증권화 노트 투자자 **70%가 반복** 참여 |
| 고액 고객 수 증가 | 매수자: NY Life·Nationwide 같은 대형 신규 AAA 매수자. 판매자: 월 $1B 규모 Flagstar, 「지금 어떤 파트너보다 큰」 파이프라인 |
| P×Q | Q = 파트너 수 × 파트너당 물량, P = 수취율. **FIGR은 P가 내려가는 중**이라 Doximity와 반대 → 마진으로 보완 설명 |
| 무료로 모아 유료로 | 매수자 무료·판매자 유료. 지금은 수취율을 낮춰 물량을 모으는 단계 |

## 2. Sportradar — 「Why not 북메이커?」 성장의 과실을 누가 먹나

**투자포인트 구조**
- Point 1 「In Play, Play Ball」 = 전방 시장(스포츠 베팅) 성장: 합법화 + CV로 인플레이 베팅 개화
- Point 2 「Better Bettor」 = **왜 동사가 최대 수혜자인가**
  - 5.1 「베팅 시장의 봉이 김선달」: **Why not 북메이커?** DraftKings는 역대 최대 매출에도 적자(마케팅비가 매출의 27%), 경기 결과에 따라 실적 변동. 반면 데이터 기업은 「베팅 사업 하고 싶어? 그럼 돈 내놔」 — 규제 강화로 데이터 우회 수집이 어려워져 북메이커는 반드시 계약. 수익 배분(GGR × take rate) 구조라 **전방 성장의 과실을 자기 것으로**
  - 도표 5-2: 스포츠 시장 6.3% < 스포츠 베팅 시장 < SRAD·GENI 매출 성장률(21~24 CAGR) — **시장 < 전방 산업 < 동사** 3단 비교
  - 5.2 과점 구조(SRAD·GENI·Stats Perform이 리그별 독점권), 매출이 2·3위 합보다 큼, 400개 리그·800곳+ 북메이커. **Sticky**: NBA와 21년 10년 연장 + 범위 확대(공동 기술 개발)
  - 도표 5-3: **매출식 분해에 경쟁우위를 하나씩 매핑**. 북메이커 GGR = 경기 수 × 경기당 옵션 수 × 옵션당 베팅액 × edge, 동사 매출 = GGR × take rate. AI → ① 경기당 데이터↑ ② 솔루션 믹스 ③ 시장 확장 → 각각 어느 변수를 키우는지 화살표로
  - 5.3~5.5 「More Data / More Solutions / More Markets, More Revenue」 세 엔진

**FIGR에 가져올 것**
| Sportradar 도구 | FIGR 대응 |
|---|---|
| **Why not 북메이커?** | **Why not 대출사?** HELOC 성장의 수혜자는 대출을 직접 만드는 IMB·은행으로 보이지만, 그들은 고객 모집비와 금리·신용위험을 진다. Connect는 실행된 대출마다 수수료를 받고, 장부를 거의 쓰지 않는다. 비교 도표: IMB(Rocket·UWM·loanDepot)의 마진 vs Figure 조정 EBITDA 마진 58% [데이터 수집 필요] |
| 「돈 내놔」(규제로 우회 불가) | 강제력은 Sportradar보다 약함(파트너는 계약상 묶여 있지 않음). 대신 「매수자를 직접 찾을 능력이 없는 IMB에게 Connect가 유일한 판로」로 |
| 시장 < 전방 산업 < 동사 3단 성장률 | 미국 1순위 모기지 시장 < HELOC 시장 < Figure 거래량 < Connect 거래량. 한 장에 넣으면 VISA 그림 13·14보다 강함 |
| 매출식 분해 + 경쟁우위 매핑 | 매출 = 파트너 수 × 파트너당 물량 × 수취율 (+ Connect 비중이 믹스를 바꿈). [1] 파트너 증가 → 파트너 수, Figure factor 2.6배 → 파트너당 물량, 매수자 증가 → 웃돈·체결률 → 파트너 몫과 물량, 은행 → 양쪽 + 수취율↓ |
| 계약 연장·범위 확대로 고착 증명 | Mutual of Omaha: Connect 전환 후 월 물량 5배, 기존 파트너 +40%, 파트너가 SMB HELOC·DSCR 등 새 상품도 Figure로(150곳+) |
| 세 엔진(Data/Solutions/Markets) | More Partners / More Buyers / More Assets(HELOC → SMB HELOC → DSCR·RTL → 자동차, 「등대 실행사」) |

## 3. Equinix — 「일일이 연결하지 않고 한 곳에서」

**투자포인트 구조(4장)**
- 4.1 소매(Retail) 코로케이션이 우월한 이유: 도매는 1~3개 대형 고객에 통째로 임대, **소매는 다수 고객이 한 건물에 있어서만 고객 간 상호연결(Interconnection)이 가능**. 2위 Digital Realty도 Telx 인수(2015)로 소매로 전환 → **경쟁사가 모델을 따라온 것이 증거**
- 고객 분산: 최대 고객 매출 비중 약 3%, 상위 50곳 약 38% → 특정 고객 의존 낮음
- 4.2 상호연결 매출 $3,670M(2018) = DLR의 16배, 3년 CAGR 18% vs DLR 9%
- 4.4 Cloud Exchange(ECX Fabric): 기업이 AWS·Azure·IBM과 **일일이 연결·관리하는 번거로움**을 동사 데이터센터의 단일 포트로 해결. 클라우드 1,600곳+ 직접 연결, 주요 클라우드 노드 점유율 AWS 45%·Azure 49%·Google 50%. **기존 코로케이션 고객이 그대로 클라우드 익스체인지를 추가로 쓰고, 이탈 유인은 낮음**

**FIGR에 가져올 것**
| Equinix 도구 | FIGR 대응 |
|---|---|
| 일일이 연결 → 한 포트 (N×M → N+M) | 매수자는 파트너 612곳과 일일이 계약·실사하지 않고 Connect 한 창구에 호가를 건다. 판매자는 매수자 25~35곳을 직접 찾지 않는다. 「612 × 30 = 약 1.8만 개 양자 관계가 1개 장터로」 같은 그림(계산은 단순 곱) |
| 소매(다수 참여자)에서만 상호연결 가능 | 양자 간 선도 매입 약정(한 매수자 ↔ 한 판매자) vs Connect(다수 ↔ 다수). 여러 파트너 대출이 한 풀로 섞여도 평가사가 한 종류로 봄(Saluda GRADE FIG6) = 다수 참여자라서 생기는 가치 |
| 경쟁사가 모델을 따라옴(DLR → 소매) | 찾아볼 것: 경쟁사·대형사가 장터형·표준 크레딧 박스로 옮기는 사례. 지금 있는 것: TPG·Saluda가 Figure 간판·대출로 증권화, Sixth Street가 Figure 증권화 선반 사용 약속 |
| 고객 분산(최대 3%) | FIGR은 아직 반대(상위 3 매수자 57%). 「집중도가 내려가는 중(상위 5: 54.4% → 44.3%)」을 트래킹 지표로 |
| 노드 점유율 | 상위 20 IMB 중 10곳, 미국 1순위 실행의 15.2%가 식별 파트너 |
| 기존 고객이 새 서비스를 덧붙임 | LOS 파트너 → Connect → Prime(온체인 창고대출) → 증권화 선반. 같은 파트너가 한 생태계 안에서 단계를 늘림 |

## 4. Circle — 「갈아엎지 않고 같이 쓰기」, 그리고 공식으로 TAM 잡기

**투자포인트 ① 구조(3장)**
- 3.1 전통 정산의 병목(승인 0.1초, 정산 수일, 일평균 $400억 이상이 묶임) → 블록체인 정산은 싸고 빠르지만 비가역성 문제 → **「가장 좋은 해법, 같이 쓰기」**: Visa가 VisaNet 승인 위에 Solana USDC 정산을 결합. **수가 적고 회전 니즈가 큰 매입사 정산부터** 시작해 발급사로 확대. 정산 규모 수백만 달러(2023) → $3.5B(25.11) → $4.6B(26.1)
- **공식으로 TAM**: MV = PT. 필요한 USDC = 월 정산액 ÷ 유통속도(5.32). Visa 미국 정산 연 $6.8조 → 상시 필요 USDC 약 $2,000억 = 「마중물이 현 시총 3배」
- 3.2 Why Arc ①~⑤(신뢰성·회계·보안·가격·확정성), **「마스터카드도 Arc에 참가했다」** → 경쟁 네트워크까지 들어온 것이 증거. 도표 3-7 「Arc 개발 주요 참여사」
- 3.3 B2B → B2C로 TAM 확장

**FIGR에 가져올 것**
| Circle 도구 | FIGR 대응 |
|---|---|
| 같이 쓰기(기존 강자와 협력) | Figure는 은행을 대체하지 않고 은행이 Connect를 쓰게 한다. Flagstar(판매) → 예금기관 20곳+ → 은행이 매수자로. 「경쟁자가 아니라 사용자」 |
| **가장 쉬운 고객부터 단계적 도입 + 숫자** | 가장 절실한 쪽(예금 없는 IMB)부터 → 서비서 → 은행. 자산군도 HELOC → SMB HELOC($500M 런레이트) → DSCR·RTL → 자동차. Connect 비중 46% → 72% |
| 공식으로 잠재 규모 | 잠재 HELOC 물량 = 파트너 1순위 실행액 × HELOC 부착률. 계산 예시는 가이드 2-B |
| 참여사 명단 도표(마스터카드도 참가) | **양면 참여자 지도**: 판매(Flagstar·loanDepot·CrossCountry·Guaranteed Rate·Lakeview·Guild 등) / 매수(NY Life·Nationwide·Sixth Street·TPG·Saluda·Bayview·Goldman 등) / 자금(JPMorgan 회전한도, Prime 대여자) |
| 블록체인 효용을 결과 숫자로 | 정산 시간·묶인 자금 대신 FIGR은 SOFR+250bp(창고대출) vs +120bp(온체인), 건당 실행비 $717 vs $11,000, AAA 255 → 135bp |

## 5. 다섯 개 보고서에서 공통으로 나온 순서

1. **점유·침투 숫자 한 줄로 시작**(의사 80%, 노드 점유율 45~50%, 매출이 2·3위 합보다 큼, 과점)
2. **한쪽이 쓸 수밖에 없는 이유를 고통 숫자로**(PA 설문, 데이터 우회 불가, 일일이 연결하는 비용, 묶인 정산 자금)
3. **반대쪽이 오는 이유를 ROI로**(ROI 11배, NRR 110%+)
4. **시장 < 전방 산업 < 동사 성장률 비교 도표**(VISA 그림 13·14, Sportradar 도표 5-2, Equinix 상호연결 CAGR 18% vs 9%)
5. **매출식 분해에 경쟁우위를 매핑**(Sportradar 도표 5-3, Doximity P×Q, VISA 거래 건수 × 14%)
6. **고착 증거**(계약 연장, 기존 고객 추가 구매, 의대생부터 가입)
7. **경쟁사·거물이 따라 들어온 것**(Digital Realty의 소매 전환, 마스터카드의 Arc 참가)
8. **위협을 기회로**(VISA: 새 결제 플랫폼도 네트워크를 거침)

FIGR은 2·3·4·5가 숫자로 가능하고, 6은 일부(+40% 코호트, Mutual of Omaha 5배), 7은 아직 약하다.
