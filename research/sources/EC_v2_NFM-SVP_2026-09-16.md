## 1. NFM은 어떤 회사인가

- **미국 10위 리테일(분산형) 대출사**, 메릴랜드 본사. LO 약 **600명**, 연 약 **30,000건** 실행.
- **HELOC 연 $600M 이상**. "HELOC은 틈새라 별도 기술 스택을 만들고 싶지 않다." [05:23]
- 전문가가 약 1년 전 NFM의 Connect 참여를 직접 연결(bridged). **2025년 6~7월 가입 → 11월경 실제 거래 시작**. [04:54]

## 2. ★ LOS → Provenance → Connect "자동 연결" [02:59, 05:23]

투자포인트 1의 "LOS를 쓰면 Connect로 들어올 수밖에" 논리에 가장 직접적인 근거예요.

- 흐름: 차주 → 대출사(NFM 또는 Figure)가 실행 → Figure Connect → 기관 자본 채널로 분산.
- 표준 심사 서류를 쓴 대출은 **진술·보장(reps & warrants)이 사실상 붙어 있음**. 소유권은 **Provenance**에 기록. Connect에 올라오면 **증권화, 홀론 매각, 유동성 수단(담보)** 중 선택 가능.
- NFM 실무: LO가 Figure LOS 기술로 접속 → HELOC 실행 → 자금 지급 → **Provenance 등록** → **Connect로 처분**. "**말 그대로 자동 연결(automatic tie-in)이다.** 우리 쪽에서 실행하고 특정 매수자에게 Connect로 밀어 넣는다."
- **화이트라벨**: Figure와 계약하면 기술 접근권을 받고, Figure가 NFM 고객용 플랫폼을 화이트라벨로 제공 → 심사, AVM, 소득 검증이 전부 Figure 인프라로.
- "**그게 은행이 이 시장을 장악했던 이유다 — 기술적으로 준비돼 있었으니까.**" [05:23] → 비은행이 HELOC을 못 했던 이유가 기술 스택이었다는 증언.
- "인프라 없이 이 대출로 돈을 번다. 가격이 항상 최고는 아니지만 LO가 HELOC 신청하기가 매우 쉽다."

### 기존 거래 방식과 비교 [02:59]
- 전통: 대출 실행 → 데이터 웨어하우스 → **비드 테이프** 배포 → 아는 투자자에게 이메일·전화 → 예비 수작업 실사 → 호가 → 합의·정산. "**지저분한 밀실 거래**. 공개 입찰이 아니다."
- Connect: 블록체인 소유권 기록·정산으로 "**훨씬 민주적**"으로.

## 3. ★ 매수자 쪽 실무 (기존 artifact에 없던 내용) [11:25 ~ 17:39]

| 항목 | 내용 |
|---|---|
| NFM 매수 규모 | **2025년 11월 이후 $200M 이상**, **월 $10~25M**. "엄청 크진 않다" |
| 승인 기간 | 약 **60일** |
| 매수자 수 | "**25, 30, 35곳**", "몇십 곳(couple dozen / several dozen)". "우리만 있는 건 아니다" |
| 매수 방식 | ① 매수자가 **원하는 대출 유형·상품·크레딧 박스 파라미터**(FICO, CLTV, DTI, 소득 검증 등)를 정함 → ② Connect가 조건에 맞는 자산·서류·세부 정보를 제시 → ③ 맞는 **풀**(예: $20~30M HELOC) 중에서 골라 → ④ **미상환 원금(UPB) 전체에 대해 입찰** |
| 입찰 투명성 | **경쟁 입찰가 비공개**(봉인 입찰). 낙찰 못 하면 사후에 **익명화 요약**만 받음("목표보다 위/아래"). PennyMac·Newrez가 얼마 썼는지는 모름 |
| 매수자 수수료 | **없음**. "매수 쪽은 참여비를 안 낸다. 매수자 참여를 원하니까." 커미션도 없음 |
| 판매자 수수료 | **1회성 연결 수수료(connection fee)** + **거래 흐름별 수수료**. "판매자가 거래 수수료를 거의 다 낸다" |
| 신용 보증 | **없음**. "그건 우리 신용위험이다." 일반적·제한적 **R&W 계약상 보호**만 있음(Figure의 명백한 오류·누락은 예외). "아마존에서 산 물건이 고장 난 것과 같다" |
| 매수 보장 | **없음**. "판매자는 체결 위험을 진다. 2달 동안 안 팔릴 수도 있다." 실제론 가격을 조정해서 팜 |
| 신용 성과 | "아직 초기. 부도율 매우 낮음." 760점·저DTI만 고르니 스스로 위험 관리. "**HELOC 부도율은 1% 미만**" |

- **같은 회사가 사고팔기도 한다** [14:33~14:57]: "직접 실행하니 보유하기 싫은 건 팔고, 보유하고 싶은 건 산다. 그래서 끊임없이 오간다." → 은행·대형 IMB가 Connect 양쪽에 동시에 설 수 있다는 근거.

## 4. 왜 HELOC에 이런 구조가 없었나 [17:48 ~ 20:56]

- Figure가 하는 것 중 새로운 조각은 없다. **실행·분배·거래·소유권 기록·정산·서비싱·증권화를 하나의 디지털 인프라에 직선으로** 넣고 표준화한 게 새로움.
- **eNote**: 2001~2002년 허용됐는데 25년이 지난 지금도 NFM 대출 중 일부만 eNote. → "모기지 환경은 극도로 파편화. 주식·채권처럼 표준화돼 있지 않다. 대출사마다 심사 기준이 다르다. 다들 다르면 진짜 시장을 만들기 어렵다."
- **모기지 업계 대출기관 약 30,000곳, HELOC 하는 곳은 약 2,800~3,000곳.**
- 거래가 "누구를 아느냐"의 관계 기반, 비전자적이었음.
- **세대 지연**: "내 나이(53) 이상이 은퇴하면 변화가 빨라질 것." Provenance는 5~6년밖에 안 됨.

## 5. 성공 가능성과 경쟁 [20:56 ~ 23:31, 27:20 ~ 31:47]

- "이미 해내고 있다. 질문은 속도가 유지·성장하냐." 멈출 수 있는 유일한 요인: **집값 정체·하락으로 HELOC 대출 흐름이 줄어드는 것**.
- 경쟁하려면 회사 하나가 아니라 **기술 플랫폼·생태계 전체**를 세워야 함 → "거대한 일".
- **MAXEX**: 가장 가까운 경쟁자. 큰 이름들이 뒤에 있고 오래 해 왔음. NFM도 과거 **점보·DSCR**을 MAXEX에 판 적 있음. "좋은 회사지만 다른 딜."
- **Optimal Blue / Polly**(가격 엔진)가 들어오면 경쟁 가능 — 하지만 "대출 가격 책정과 실행은 다른 기술·문화·리더십. Optimal Blue 같은 25~30년 된 회사엔 정체성 전환".
- **"3의 법칙"**: 건강한 시장은 3강. 여긴 **2강(Figure, MAXEX)**뿐이고 3번째가 안 보임. 너무 파편화돼 있고 투자 자본이 부족. 따라잡으려면 **최소 5년 전략, 현금 대량 소각**. "꽤 보호돼 있다."
- **ICE/Encompass 붕괴론** [27:20]: "Encompass는 아직 지배적 LOS지만 **모두 떠나고 싶어 한다**. **Vesta**를 진지하게 본다." → Figure 전략에 우호적인 병행 추세. ← 기존 artifact에 없음
- 규제가 무거운 환경 + 경쟁자 적음 + 이미 한 분야 지배 + 같은 틈새 전략을 다른 상품에 적용 → 강세. DSCR 쪽 Deephaven 등은 "구식, 기술 지향 아님".
- "투자 관점이 아니라 **사용자 관점에서** 강세."

## 투자포인트 1에 주는 함의 (내 해석)

1. **매수자 풀은 실재한다(25~35곳), 다만 얕다.** Sixth Street가 지배적이고 Goldman·Texas Capital·Deutsche 정도가 이름이 나옴. "매수자가 늘어난다"를 주장하려면 이 숫자의 추세(10-K "참여자 48곳"과 비교)가 필요.
2. **대출사가 매수자도 된다.** NFM이 사고팔기를 동시에 함 → 투자포인트 1의 "양방향" 그림에서 **은행뿐 아니라 대형 IMB도 매수자로 전환**될 수 있다는 근거.
3. **매수자 무료 + 판매자 유료**는 전형적인 양면 플랫폼 가격 정책(유동성 쪽 보조). 매수자가 늘면 판매자 가격이 좋아지는 플라이휠과 맞음.
4. **"LOS → Connect 자동 연결"** 증언 확보. 다만 v3와 합치면 인과는 "Connect 유동성 때문에 LOS를 쓴다"에 가까움.
5. **경쟁 지도에 MAXEX·Optimal Blue·ICE/Encompass·Vesta 추가 필요.** "3의 법칙" 프레임은 보고서 문장으로 쓰기 좋음.
6. 이 전문가는 **매우 낙관적**이고 Figure와 직접 계약 관계는 아님 → 인용할 때 가중치 조절.
