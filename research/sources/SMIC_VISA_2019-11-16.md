## 1. 보고서의 논리 순서 (3장 「카드결제 시장의 성장」이 핵심)

1. **시장이 커진다** (3.1)
   - 2015~2017년 미국·유럽 카드 결제 횟수 연평균 +10.96%, 결제금액 +7.76%
   - 성장 여력: 미국 거래 건수의 37%, 유럽 POS 거래의 79%가 아직 현금. e-commerce가 카드 발급을 끌어올림. 프랑스·스웨덴의 현금 억제 정책
2. **동사는 시장보다 더 크게 성장했다** (3.2.1) ← 주장보다 **실증을 먼저** 둠
   - VISA 매출 2012년 $10,421M → 2019년 $22,977M, CAGR 16.6%
   - 미국 카드 거래액 2012년 $4.65T → 2017년 $6.48T, CAGR 6.8%
   - 같은 기간(12~17년)만 봐도 VISA 12% vs 시장 6.8%. Mastercard도 10%
3. **왜 시장보다 크게 크나** (3.2.2)
   - **네트워크 효과**: VISA 카드 소지자↑ → VISA를 받는 상점↑ → VISA 카드 발급↑. 초반에 규모를 못 키운 곳은 도태 → 과점 → 시장 성장분을 더 크게 가져감. 설명은 팩스 비유 하나
   - **규모의 경제**: Network & Processing 비용이 매출이 두 배 되는 동안 약 40%만 증가. 인건비 외 비용 항목의 매출 비중이 해마다 하락 → 순이익이 매출보다 빨리 큼
   - **가격결정력**: 매입사는 가맹점이 골라 쓰니 가격결정권이 없지만, 네트워크 수수료는 협상 불가. 해외결제 환전율에서 VISA가 Mastercard보다 비쌈, 한국 카드사 수수료 1.0% → 1.1% 인상
4. **위기가 아닌 기회** (4장)
   - 애플페이·삼성페이·Venmo·Zelle·PayPal·Square 등 결제 플랫폼이 쏟아져도 **카드 기반인 이상 네트워크사가 배제되지 않는 구조**(그림 17 「미국 결제 시스템 생태계의 변화」)
   - 결제 플랫폼 다양화 = 전방 시장의 다각화. 새 플랫폼과의 접점(M&A: Earthport·Payworks·Rambus·Verifi, 제휴: Go-Jek·Toss 등, Visa Direct)을 넓히는지가 관건
5. **밸류에이션** (5장): 거래 건수 추정 → Service + Data processing 매출이 거래 건수의 일정 비율(2017년부터 14%)이라는 관계로 매출 추정

부가로 볼 것
- 1.2절 수익 구조: 데이터 프로세싱 35%(건당 약 $0.07), 서비스 32%(거래액의 0.11%), 국제거래 27%(약 1%). **총수익의 약 20%를 인센티브로 고객사에 되돌려줌**(계약 연장 유인, 마케팅 비용 성격)
- 2.1절 연혁: BoA의 BankAmericard → 다른 은행에 라이선스 → 신뢰 문제(연체·사기)로 은행 공동법인 → VISA. 3당사자 → 4당사자 모델로 네트워크가 분리된 이유가 「보안·신뢰에 대한 법적 책임」

## 3. VISA 보고서에서 배울 것, 피할 것

- **배울 것: 순서.** 「시장이 큰다 → 동사는 시장보다 더 큰다(숫자) → 왜(구조)」. 주장보다 실증 도표를 먼저 둬서 「왜」가 사후 설명이 아니라 관찰된 사실의 원인 분석으로 읽힘.
- **배울 것: 위협을 기회로 뒤집는 장.** 「새 플랫폼이 나와도 다 네트워크를 거친다」. FIGR에선 「Aven·Pylon·SoFi가 대출을 만들어도, 팔 곳은 필요하다」로 쓸 수 있는데, 지금은 외부 LOS 대출의 Connect 물량 숫자가 없어서 약함.
- **피할 것: 네트워크 효과를 비유로만 주장.** VISA는 이미 과점이라 결과가 증거였지만, Connect는 출시 2년(2024.6)이라 세션에서 「양쪽이 정말 늘고 있냐」를 숫자로 물을 것. 파는 쪽 숫자와 사는 쪽 숫자를 **따로** 대야 함.
- **차이: 가격결정력.** VISA 3.2.2.3을 그대로 가져오면 바로 반박당함(수취율 하락). FIGR은 「수취율을 낮춰 판을 키우는 단계, 그래도 마진은 오른다」로.
