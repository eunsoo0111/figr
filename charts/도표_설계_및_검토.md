처음 초안의 도표 제목과 비교:
- 3-1(금융위기 전후 유통액·사건): 유지. 2006~21년 연간 시계열이 없어 **축 생략 + 세로 타임라인**으로 처리
- 3-2(차주 입장에서 HELOC을 쓸 이유): 유지하되, 말로 쓴 논리를 **실질 조달금리 계산**으로 바꿈
- 3-3(동사 HELOC vs 기존 HELOC): 유지, 10-K·10-Q 숫자로 채움
- 3-4(은행 밖 HELOC의 표준: 비은행 HELOC 금액과 동사 물량) → **양면 플랫폼 도식**으로 교체. 비은행 HELOC 총액은 HMDA 전체 원자료(수백만 건)와 금융기관 업권 분류가 필요해 이번엔 확보하지 못함(아래 4절)
- 3-5(파트너 도입 이후 물량) → **분기 거래량 + 파트너 수**로 교체. 파트너별(loanDepot·Lakeview·14곳) 물량은 공시 원자료가 없음(아래 4절)
- 3-6(1순위가 걸은 길), 3-7(같은 은행, 다른 출구): 유지, 1차 원자료(Fed Z.1, HMDA)로 직접 계산
- 3-8: 3.4절 뒷부분(21~25)에 도표 자리가 없어 새로 추가

## 4. 확인 필요·미확보 원자료 (있으면 도표가 나아지는 것)

1. **2006~2021년 2순위 증권화 연간 발행액**(Inside Mortgage Finance 또는 Finsight) → 3-1의 축 생략 구간을 실제 막대로 채울 수 있음. 22년(약 10억)·24년(약 120억)도 연말 확정치로 교체 권장
2. **비은행 HELOC 실행 총액과 동사 시스템 물량(HMDA 전체)** → 처음 구상한 "은행 밖 HELOC의 표준" 도표. HMDA 2025 전체 LAR(2순위·개방형)과 금융기관 업권 분류(예금기관/비예금기관)가 필요
3. **파트너별 도입 전후 HELOC 물량**: 확인된 파트너와 본문에 나오는 파트너 21곳(Rate·Homebridge·CMG·CrossCountry·Fairway·The Loan Store·Union Home·Movement·loanDepot·NAF·NFM·Lakeview·Mutual of Omaha·Flagstar 등)의 HMDA 2021~2025 HELOC 실행액을 `raw/hmda_partners/`에 받아 둠(`raw/hmda_partner_agg.py`). 예: CrossCountry 0 → 5.3억 달러(25년), The Loan Store 0 → 7.8억 달러. 도표로 쓰기 전 확인할 점: ① 2022~23년 파트너 명의 물량이 0인 곳이 많은데 당시 동사(Figure Lending)가 대출 명의자였던 것으로 보임 ② Lakeview·NFM은 25년까지 자사 명의 HELOC이 0 ③ 역모기지(HECM) 제외 처리를 아직 안 해서 Mutual of Omaha 같은 역모기지 대형사는 과대 집계됨 ④ loanDepot의 2026년 물량은 HMDA(27년 봄 공시) 전이라 금액 원자료가 없음(회사 공시는 '2Q26 HELOC 물량 237% 증가'만)
4. 동사 HELOC ABS의 딜별 AAA 가산금리(3년 새 절반) → 문단 10을 받치는 선 차트 후보
5. 3-2의 기존 금리 3.5%는 예시 가정(FHFA 최빈 구간 3~4%의 중간값). 다른 가정을 쓰려면 엑셀 '도표 3-2'의 '기존 금리' 값만 바꾸면 수식으로 다시 계산됨

## 5. 남은 양식 경고와 이유

- 3-1 세로축 단위 없음: 왼쪽 작은 차트(폭 2.6cm)는 LibreOffice가 축 제목을 세로로 꺾어 그려서, "(십억 달러)"를 같은 위치에 글자 상자로 넣음
- 3-2 범례 없음: 금리 구간 이름을 막대 안에 직접 적어 범례가 필요 없음
- 3-5: 24.3Q 파트너 수는 공시가 없어 빈칸으로 두고, 선은 앞뒤 분기를 이어 그림
- 3-2·3-8 가로축 레이블 겹침 경고: 3-2는 두 줄 레이블을 한 줄 길이로 잰 오탐, 3-8은 패널 안 작은 차트(4.05×1.95)라 경고가 뜨지만 렌더에서 겹치지 않음
- 3-8 차트 크기 경고: 도식 안에 넣은 작은 차트라 의도된 크기
